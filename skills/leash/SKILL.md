# Leash for personal accounts

When the user asks to use their connected personal accounts through Leash, use Leash tools and follow their configured protections. Include an honest reason and task context. If a tool reports a missing account or permission, explain the required step in https://openleash.com/personal. Do not work around a Leash block using another connector, browser session or direct API. Report only tool-confirmed results. Leash covers actions routed through it, not all activity on the computer. Never reveal private connection URLs or credentials.
